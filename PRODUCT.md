# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

React + Vite + TypeScript + Tailwind CSS (as defined in TECHSTACK.md and IMPLEMENTATION.md Phase 9)

## Users

1. **Everyday Shoppers & Kirana Customers:** Older shoppers, regional-language speakers, and buyers who prefer sending voice notes or snapping handwritten lists on WhatsApp over navigating complex websites or apps.
2. **Merchants & Store Owners:** Kirana owners, D2C brand managers, restaurant operators, and lead-gen businesses operating their catalog, orders, and human takeover via the web back-office dashboard.

## Product Purpose

VartaCart / Vyapaar is an AI-powered WhatsApp commerce and sales infrastructure platform. It brings e-commerce directly into natural conversations on WhatsApp, using voice notes, photos of handwritten lists, and natural language as first-class inputs, while providing merchants with a real-time web back-office dashboard.

## Positioning

"AI understands intent. Deterministic code handles money."
Unlike rigid "Press 1" chatbots or hallucinating LLMs, VartaCart combines multilingual multimodal understanding (Gemini) with deterministic transactional services (integer paise pricing, inventory locking, verified payment webhooks, and DPDP consent enforcement).

## Operating Context

- **Front Storefront:** WhatsApp Business Platform (Cloud API, WhatsApp Flows, interactive buttons/lists/catalogs).
- **Merchant Back-Office:** React + Vite + TypeScript dashboard (`apps/dashboard`) managing overview KPIs, live conversations, RTO Shield risk review, catalog/inventory, customer retention ("My Usual"), and lead pipelines.

## Capabilities and Constraints

- **Multi-modal Input:** Speech-to-text for Hinglish audio notes, OCR for handwritten grocery lists, and visual matching for unknown products.
- **Golden Rules Enforced:**
  1. Prices and stock come strictly from database tools, never free-generated by AI.
  2. Orders are created only upon explicit customer confirmation.
  3. Payments are marked `paid` only upon verified payment webhook arrival.
  4. Database multi-tenancy enforced via Row-Level Security (RLS).
  5. Integer paise for all monetary values.
  6. Human takeover silences AI immediately for that conversation.

## Brand Commitments

- Name: VartaCart / Vyapaar
- Voice: Warm, accessible, organic, respectful Indian commerce ("Namaste / Bhaiya").
- Color Palette: Deep Forest (`#0A3622`), Warm Ivory Canvas (`#FBFBF8`), Soft Mint (`#E8F5EE`), WhatsApp Emerald (`#10B981`), Warm Amber Accent (`#F59E0B`).
- Typography: Instrument Serif (editorial display), Plus Jakarta Sans (interface), JetBrains Mono (data/timestamps).

## Product Principles

1. **Accessibility First:** Customers buy using natural voice and photos without learning e-commerce workflows.
2. **Zero-Tolerance Financial Integrity:** No floating-point money math, no unverified paid states, no cross-tenant leakage.
3. **Human-in-the-Loop CRM:** Automated agents handle repetitive orders and escalate with clear summaries when confidence is low.
4. **Fairness Over Proxies:** RTO Shield assesses individual behavior and never blacklists geographic pincodes.
